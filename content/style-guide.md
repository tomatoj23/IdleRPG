# 文风指南（叙事内容硬约束）

所有叙事字段（怪物/装备/武功描述、奇遇事件、combat-text 模板与词库、lore 长文）必须遵守本指南。Schema 校验管格式，本指南管语体——两者都是硬门禁。

## 总纲

- **语体**：古典白话武侠（金庸式叙事为基准，古龙式短句可选作风味变体），不是网文爽文体，不是修仙文，不是西幻。
- **视角**：第三人称或对玩家的第二人称"你"，同一集合内保持一致。
- **长度**：单条描述 1~3 句；奇遇事件 3~6 句；lore 长文不限但须成段成章。

## 用词规范

**必须使用**（与 `CONTEXT.md` 术语一致）：
- 境界序列：不入流 / 三流 / 二流 / 一流 / 绝顶 / 宗师
- 武功分**招式**与**心法**，品阶称**黄阶 / 玄阶 / 地阶 / 天阶**
- 学习武功的道具称**秘籍**；配方称**丹方**；配方解锁、**门派贡献**兑换
- 装备档位称**普通 / 魔法 / 稀有 / 传说**；战斗场景称**秘境**（分**层**）
- 离线收益叙事称**闭关**，上限叙事称"闭关有期限"

**禁止出现**：
- 现代词汇：系统、面板、玩家、经验值、金币、副本、boss、 buff、技能点、充值、VIP
- 修仙词：金丹期、元婴、灵气、渡劫、飞升（题材是武侠不是修仙）
- 西幻词：法师、魔法值、公会、精灵
- 数值直出的干瘪句："造成 100 点伤害"（应写"受创 100 点"类描写，数值由模板槽位填入）

**敏感边界**：不出现真实历史人物姓名与真实朝代年号；江湖门派为架空；不写血腥细节（"筋断骨折"可，肢体残缺描写不可）；不涉政治。

## combat-text 模板规范

- 模板使用 `{槽位}` 变量：`{攻击者} {受击者} {招式} {动词} {部位} {后果} {伤害}` 等，变量名与 `docs/agents/content.md` 的约定一致
- 每个模板 1~2 句；后果描写词库按**轻伤 / 中伤 / 重伤 / 濒死**四档分池，档内词条风格一致
- 暴击 / 闪避 / 反伤 / 中毒 各有专属模板池；天阶招式模板可到 3 句的华丽长句
- 招式名出现时用「」括起：「白虹贯日」

## 示例（风格基准）

> 你使出一招「白虹贯日」，剑尖直取黑衣人咽喉！黑衣人侧身急闪，剑风扫落一缕鬓发，堪堪避过。

> 这柄"流云剑"乃百炼精钢所铸，剑身隐有云纹流转。剑鞘是江南水牛皮所制，虽非名贵，胜在趁手。

> 你在后山采得一支七叶灵芝，根须犹带山岚湿气。老药师眯眼端详半晌："成色上佳，够炼一炉小还丹了。"

## agent 批量生产守则

1. 先读本指南与目标集合的既有条目，对齐语体再动笔
2. 同一批次产出的文本避免句式雷同（连读三段不得使用相同句式开头）
3. 产出后运行 `npm run content:check`，并自查本指南"禁止出现"清单
