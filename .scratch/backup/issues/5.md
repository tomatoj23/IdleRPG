## What to build

掉落与装备穿戴：修饰符聚合引擎作为独立基础设施先行落地（固定值 → 加法百分比 → 乘法区三层计算）；装备生成（底材带固有词缀 × **稀有度 寻常/精良/罕见/绝世（0 / 1~2 / 3~4 / 5~6 词缀，绝世含一条特色词缀）** × 词缀阶位 T1~T3）；掉落等级由秘境层数决定；背包与穿戴（6 槽位，槽位数来自 config）；角色面板由修饰符聚合实时计算。

## Acceptance criteria

- [ ] 词缀、心法、增益共用同一条修饰符管线；任何系统禁止绕过修饰符直改属性（评审与测试保证）
- [ ] 掉落分布可由固定种子 rng 确定性复现；词缀阶位受掉落等级约束
- [ ] 同一套装备在聚合引擎下面板计算结果唯一且可测
- [ ] 穿戴/卸下后面板实时变化并反映到战斗数值
- [ ] 装备数据结构预留 socket 字段位
- [ ] 稀有度命名与档位规则全部在 config，引擎无写死数量

## 更新说明（2026-08-30）

稀有度命名改为武侠语汇 **寻常/精良/罕见/绝世**（原为 普通/魔法/稀有/传说）。依据 ADR-0008 与 `CONTEXT.md`：术语表已将「品阶」专用于武功档次（下乘/中乘/上乘/绝学），装备档次统一称「稀有度」；"传说""魔法"为西幻词，已列入 Avoid。词缀条数规则不变。
