## What to build

MUD 叙事层：combat-text 模板引擎（UI 层，消费事件语境选模板渲染）；模板与后果词库作为内容文件：**按伤害占比分四档（轻/中/重/濒死），每档内再按伤害类型分池（割/刺/瘀/内伤/抓伤，各类 6~9 条递进文案）**；**显示档位**（不堪一击→…→返璞归真，由 config 从数值推导）用于造诣类描述；频率控制（普通命中短句、暴击/品阶/关键节点完整描写）；按 style-guide 批量生产初版模板与词库（agent 产出、过校验）。文风与呈现基准同 #10，见 `docs/design/ui-direction.md` 与 `docs/research/xkx100-kungfu-combat.md`。

## Acceptance criteria

- [ ] 同一事件按伤害占比档位渲染对应后果词库档
- [ ] **同一档位内不同伤害类型命中不同词库池（事件含 damageType），并有测试断言**
- [ ] 暴击/闪避/反伤/中毒各有专属模板池；招式名以「」呈现
- [ ] 模板缺失时回退为短句，不崩溃不空文案
- [ ] 频率控制可测：普通命中不触发长描写
- [ ] 文本模板与词库为内容文件，遵守 style-guide，通过校验
