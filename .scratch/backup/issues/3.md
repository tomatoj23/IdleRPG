## What to build

突破循环：突破命令（修为攒满 + 材料门槛，门槛材料含突破丹）；物品与背包系统初版（突破丹是首个材料）；角色面板显示境界与修为进度；突破成功后的境界演出（演出强度按 config 分级）；基础数值随境界提升（数值直接来自 config 曲线）。

## Acceptance criteria

- [ ] 修为未满或材料不足时突破被拒绝并给出明确反馈

- [ ] 境界序列、突破材料需求曲线全部由 config 驱动
- [ ] 演出强度按境界分级（config），突破事件进入事件流
- [ ] 全部行为经引擎门面确定性测试
