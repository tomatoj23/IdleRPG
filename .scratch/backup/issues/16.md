## What to build

MVP 内容盘子补齐：由 AI agent 按 `docs/agents/content.md` 与 `content/style-guide.md` 批量生产至规格盘子——3 门派 × 8~10 武功（**品阶统一用 下乘/中乘/上乘/绝学**，含前置要求）；词缀池 20+ 条 × 3 阶；3 秘境 × 10 层完整怪物表；药材 9 种；丹方 6 张（2 突破丹 + 4 增益丹）；奇遇 20 条；combat-text 全量模板与词库（**按伤害类型分池**）；lore 初版（世界背景）。

门派条目需含 `masters`（师父）字段，承载可教武功池与贡献规则（与 #8 一致）。

内容条目需标注**归属**（`sectId`/`regionId`），`content/config/` 增加**显示档位**（displayTiers）配置。每批次产出后过 content:check 并人工抽查。

## Acceptance criteria

- [ ] 内容量达到规格盘子，content:check 全绿
- [ ] style-guide 禁词清单自查通过，同一批次无雷同句式开头
- [ ] id 命名符合约定且全库唯一（含资产约定路径）
- [ ] **命名语汇全部符合 `CONTEXT.md`**：武功品阶 下乘/中乘/上乘/绝学；装备稀有度 寻常/精良/罕见/绝世；无"黄阶/玄阶/地阶/天阶/传说/魔法"等旧词
- [ ] **条目归属字段（sectId/regionId）齐全**，校验器通过覆盖与连通检查
- [ ] **门派条目 masters 字段齐全**，可教武功池与门派武功池一致
- [ ] **显示档位配置就位**，战斗文本与界面可从数值推导造诣描述
- [ ] 满内容下全流程可玩：闭关→突破→秘境→刷装→分解洗练→炼丹→排行
- [ ] 每批次汇报新增/修改的 id 清单
