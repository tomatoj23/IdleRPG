## What to build

战斗视觉层：战斗页头像对峙布局；占位符系统（按 id 哈希配色 + 稀有度边框，`assets` 约定路径存在时优先采用）；血条与增益状态栏；飘字（伤害、暴击放大变红、属性配色、闪避（未命中））；角色头像边框随境界分级（**复用稀有度配色表，配色表在 config**）；**战斗日志支持折叠为仅结论**。

**视觉依据**：`docs/design/ui-direction.md` 与基准图 `docs/research/ui-mockups/approved/desktop-battle.png`、`mobile-loadout.png`（清新淡雅水墨、写实非卡通、武侠而非仙侠）。

## Acceptance criteria

- [ ] 零美术资产时全部由程序化占位符渲染，不报错不空缺
- [ ] 将图片按命名约定放入 assets/ 即被采用，无需改代码
- [ ] 视觉强度由事件语境驱动：暴击/伤害类型/境界改变飘字与边框表现
- [ ] 配色表与阈值在 config，UI 组件不含题材词汇
- [ ] 战斗日志可折叠为仅结论（放置玩家挂机后只看结果，来自 UI 调研）
