## What to build

内容编辑器（apps/editor）：本地 dev server 提供内容目录读写 API；Schema 驱动的表单视图（字段类型/枚举/范围校验自动生成）；表格视图（集合全量平铺、多选批量数值调整：加减/乘系数/覆盖、文本批量替换）；保存写回 content/ 的 JSON 文件，保存前触发 content:check，git 可见 diff。

## Acceptance criteria

- [ ] 编辑任意集合并保存，产出通过 Schema 校验的合法 JSON
- [ ] 非法输入在表单层被拦截，无法写入
- [ ] 多选 N 条后一次完成数值批量调整；文本批量替换可用
- [ ] 编辑器表单由 Schema 驱动，无独立数据模型（Schema 演进即编辑器演进）
- [ ] 保存后 git diff 能看到精确变更
- [ ] 编辑器新增依赖只进 workspace 依赖清单，禁全局安装或改动本机环境（ADR-0007）
