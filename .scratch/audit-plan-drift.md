## 三、逐项建议改动（可直接执行）

### #1 规格
1. 「两条硬性标准」→「三条硬性标准」，新增：
   > 3. **依赖环境项目内自包含**（ADR-0007）：禁止 `npm install -g`、`corepack enable`、修改全局配置；包管理器用 `corepack pnpm`（版本由 `packageManager` 锁定），包缓存在项目内 `.pnpm-store/`；新依赖只进 workspace 清单。
2. 实现决策中装备条目：稀有度（普通 0 / 魔法 1~2 / 稀有 3~4 / 传说 5~6）→ **（寻常 0 / 精良 1~2 / 罕见 3~4 / 绝世 5~6）**
3. 实现决策中武功条目：品阶 黄/玄/地/天 → **下乘 / 中乘 / 上乘 / 绝学**
3b. **用户故事 24**「程序化占位符（按 id 哈希配色+品阶边框）」与**资产决策**「程序化占位符（id 哈希配色 + 品阶边框）」→ 两处「品阶边框」均应为 **「稀有度边框」**（品阶已专指武功档次）
4. 实现决策补充：
   > - 武功条目含**前置**（先修武功与等级）；战斗事件语境含**伤害类型**（割/刺/瘀/内伤/抓伤）
   > - 生产活动含**等级**（`level`/`xp`），与境界门槛共同决定采集区解锁
   > - 内容条目用 `sectId`/`regionId` 表达**归属**，校验器检查覆盖与连通；不做目录分层
   > - **显示档位**（不堪一击→…→返璞归真）由 config 推导，供战斗文本与界面使用
5. 新增「## 后续决策（2026-08-30 追加）」节：引用 ADR-0007、ADR-0008、`docs/design/content-capacity.md`、`docs/design/ui-direction.md`，并说明承载边界（不做任务/知识技能/NPC 集合）。
6. Out of Scope 补充：任务体系、知识/生活技能、NPC 独立集合（显式不做）。

### #4 秘境战斗（补一行）
- What to build 中「事件携带完整语境（伤害值、是否暴击、伤害占目标血量比例、来源与命中类型标志）」→ 增加 **「伤害类型（割/刺/瘀/内伤/抓伤）」**
- AC 中「事件携带完整语境字段」→ 增加 damageType 字段断言

### #5 掉落与装备
- 「稀有度 普通/魔法/稀有/传说」→ **「稀有度 寻常/精良/罕见/绝世（0 / 1~2 / 3~4 / 5~6 词缀）」**

### #6 武功装配
- 「品阶 黄/玄/地/天」→ **「品阶 下乘/中乘/上乘/绝学」**
- 增加：武功 Schema 含**前置**（先修武功与等级要求）；装备词缀与武功通过标签联动
- AC 增加：有前置要求的武功在前置未满足时不可学习，并给出明确反馈

### #7 采药炼丹
- 「采药场三区三阶（按境界解锁）」→ **「采药场三区三阶，按境界门槛 + 生产活动等级共同解锁」**
- AC「境界门槛控制可进入的采药区」→ 增加 **「活动等级门槛同样生效；等级与经验存于存档」**

### #8 门派贡献
- 「门派内容（可学武功池、生产类加成）」→ 增加 **「师父（`masters`）字段：承载可教武功池与教学规则；不立独立 NPC 集合（ADR-0008）」**
- AC 增加：门派条目的 masters 字段通过 content:check

### #10 战斗视觉层
- What to build 增加：**视觉依据见 `docs/design/ui-direction.md` 与 `docs/research/ui-mockups/approved/`（desktop-battle.png、mobile-loadout.png）**
- 「复用品阶配色体系」措辞 → **「复用稀有度配色表（config）」**

### #11 MUD 叙事层
- 「模板与四档后果词库（轻/中/重/濒死）」→ 增加 **「并按伤害类型分池（割/刺/瘀/内伤/抓伤，各 6~9 档递进文案）」**
- 增加：**显示档位**（不堪一击→返璞归真）由 config 推导，用于战斗文本中的造诣描述

### #12 奇遇事件
- 增加：**纯叙事道具用标签表达**（普通条目 + `tags:["quest"]` + 价值归零），不建特殊类型

### #13 / #14 云存档 / 排行榜
- 各补一行：**CloudBase SDK 只进 workspace 依赖（`@idlerpg/web` 的 dependencies），禁止全局安装或改动本机环境（ADR-0007）**

### #16 内容盘子
- 命名语汇统一：武功品阶 下乘/中乘/上乘/绝学；装备稀有度 寻常/精良/罕见/绝世
- 增加：内容条目标注 `sectId`/`regionId` 归属；校验器检查覆盖与连通
- combat-text 词库按 damageType 分池；config 增加 displayTiers（显示档位）
- AC 增加：归属字段与显示档位通过 content:check
